# CNC Versions

This directory contains the four reference CNC machine versions that will be analyzed and organized during development.

## Versions

- `version-01/` — Reference CNC Version 1
- `version-02/` — Reference CNC Version 2
- `version-03/` — Reference CNC Version 3
- `version-04/` — Reference CNC Version 4

Each version should keep its original images, CAD, mechanical information, electronics, drawings, and notes separated from the others.
